BRAIN AND NERVOUS SYSTEM UNDER EXTREME STRESS — INTERACTIVE PRESENTATION

1. Remove any older extracted Brain_Stress_Interactive_3D folder and unzip this package.
2. Open Command Prompt in the extracted folder and run:
      python -m http.server 8861
   On some Windows systems use: py -m http.server 8861
3. Open http://localhost:8861 in Chrome or Edge and choose Present full screen.
4. Use the left/right arrow keys or the seven topic buttons. Drag the 3D brain to rotate it. Scroll to zoom within the safe range. Reset view returns to a side view. Space pauses rotation.

The first four sections use a complete segmented 3D brain. The selected region lights up and its relevant white-matter pathway glows. The amygdala and pathway meshes are registered to the full brain approximately for an educational demonstration. These lines illustrate anatomical pathways, not a real-time measurement of neural firing. The next three sections retain the sympathetic, parasympathetic and vagus nerve illustrations from your original slides with animated paths.

The reticular activating system is a distributed brainstem network, so its highlighted area is approximate. The prefrontal selection groups frontal cortical surfaces. Educational use only, not a clinical map.
