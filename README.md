# Brain and Nervous System Under Extreme Stress

An interactive educational presentation with a rotatable 3D brain, highlighted regions and pathways, and animated nervous system illustrations.

## Vercel deployment

Import this repository in Vercel as an **Other** framework project. Leave the build command empty and set the output directory to `.` (repository root). Deploy. The site is static and needs no environment variables or server.

For local preview, run `python -m http.server 8861` in this directory, then open http://localhost:8861.

## Controls

Use arrow keys or topic buttons to move through the presentation. Drag to rotate the brain; scroll to zoom; Space pauses rotation.
